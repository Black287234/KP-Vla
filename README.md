# StationeryAccounting — модуль учёта движения канцелярских товаров

Курсовой проект, тема №19: «Проектирование и разработка модуля учета движения канцелярских товаров».
ЧПОУ «Сургутский колледж предпринимательства», 2026.

## Что нужно установить
- .NET SDK 8.0 (проверка: `dotnet --version` — должно начинаться с `8.`)
- Git (проверка: `git --version`)
- Интернет при открытии страниц (стили Bootstrap подключаются с CDN)

## Запуск (PowerShell)
```powershell
cd "$env:USERPROFILE\Documents\Kursovye\StationeryAccounting"
dotnet run --project StationeryAccounting
```
Открыть в браузере: http://localhost:5080

## Основные адреса
| Адрес | Что показывает |
|---|---|
| `/` | Главная страница |
| `/Products` | Справочник товаров |
| `/Products/Details/1` | Карточка товара |
| `/api/products` | Все товары в JSON |
| `/api/products/1` | Один товар в JSON |

## Текущее состояние (этап 1)
Данные хранятся в памяти (статический список в `Data/ProductStore.cs`) и сбрасываются при перезапуске.
На этапе 2 хранение будет переведено на SQLite + Entity Framework Core.

## Структура
- `Models/` — классы данных (товар)
- `Data/` — хранилище данных
- `Services/` — логика работы с данными
- `Controllers/` — обработка запросов (страницы и API)
- `Views/` — страницы Razor
